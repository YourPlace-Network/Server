# Living off the Land
### Running YourPlace in a completly self-sufficient matter

The YourPlace server is an open-source project which allows anyone to parse and aggregate the YourPlace protocol over many different networks and blockchains. It is a simple JSON protocol, and we give you all the tools necessary to publish and traverse a multitude of social media networks.

* Host your own YourPlace server

Hosting your own YourPlace server allows you a place to publish and consume social media content. Ownership of your profile is tied to your wallet address, so only you have the keys. The server also allows you to read other blockchains and social media networks, and gives you a central view of your online presence

* Run your own Blockchain RPC nodes

Running your own RPC nodes is critical to fast service and decentralization. You can build your own RPC nodes at home, or use the "full node" features of YourPlace server to set up that infrastructure for you. This gives the YourPlace server direct access to distributed networks, so you can read and publish directly


### Advanced

* Run YourPlace server behind a Tor hidden service

Tor is the ultimate in online privacy, and running a YourPlace server behind a Tor hidden service is technically possible. This would ensure that a YourPlace server cannot be tracked and would be considered a darknet service.
