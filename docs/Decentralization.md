To set up your own YourPlace infrastructure, you need the following components:
* js-libp2p signalling server - https://github.com/libp2p/js-libp2p-webrtc-star
* ipfs p2p-circuit server - https://blog.ipfs.tech/2021-06-10-guide-to-ipfs-connectivity-in-browsers/#%E2%9A%A1-p2p-circuit
* nf.domains seems to require the querying of a centralized API - no clear way to query their info via algod or an indexer
